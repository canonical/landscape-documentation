# 26.10 release notes

> Landscape Server 26.10 runs on Ubuntu 26.04 LTS Resolute Raccoon, 24.04 LTS Noble Numbat, or 22.04 LTS Jammy Jellyfish. Database schema changes are required to upgrade to Landscape Server 26.10.

You can now access Landscape 26.10 in our `latest-stable` rolling release PPA: `ppa:landscape/latest-stable`.

Landscape SaaS will receive these updates as a phased rollout.

Note that 26.10 is not an LTS release. For self-hosted production deployments, we recommend using an LTS release, such as {ref}`Landscape Server 26.04 LTS <reference-release-notes-26-04-lts>`.

## Highlights

- **Changed default web portal**: Landscape 26.10 now uses the modern web portal by default instead of the legacy web portal. Users are directed to the modern web portal when logging in, but the legacy web portal remains available. On self-hosted Landscape, this is controlled by the `login_to_portal` key under `[features]` in the `service.conf` file, which is enabled by default. For Landscape SaaS users, this change will be introduced through a phased rollout.

- **Bulk package management**: Manage packages across multiple instances at once. In the web portal, Deb management and Snap management on the Instances page act on multiple selected instances. Deb management shows a summary of the planned changes, including packages excluded on selected instances, before you run them. Snap management supports bulk snap actions. Both are unavailable for a selection with no instance that supports them, and the web portal warns when a selection exceeds the package management limits. Deb management uses package change plans, which you can also use in the REST API. A plan can install, remove, upgrade, hold, unhold, or change the version of packages, and is limited to 100 instances and 500 packages. Package change plans are enabled by default on self-hosted Landscape and are controlled by the `package_change_plans` key under `[features]` in the `service.conf` file.

- **Package search**: Search for packages across instances with the REST API endpoints `POST /packages:search` and `POST /packages:search-upgrades`, or in a single instance with `GET /computers/{computer_id}/packages/search`. Package search is enabled by default on self-hosted Landscape and is controlled by the `package_search_rest_api` key under `[features]` in the `service.conf` file.

- **Compliance report**: `GET /computers/compliance-report` returns a compliance and security report for up to 10,000 instances. It is enabled by default on self-hosted Landscape and is controlled by the `instance_reports` key under `[features]` in the `service.conf` file. The web portal shows the instances report side panel when this feature is enabled.

- **Web portal URL**: The web portal is now served at `/portal/` instead of `/new_dashboard/`. Requests to `/new_dashboard/` are redirected to `/portal/` with an HTTP 301 response.

## Additional Updates

- The `landscape-api` snap will be officially deprecated starting in Landscape 27.04
- `GET /packages` and `GET /computers/{computer_id}/packages` are deprecated in the REST API v2. They remain available, and their responses include a `Deprecation` header
- Legacy web portal endpoints that change state, including upgrade profile removal, now require `POST` requests
- WSL profile and USG profile limits no longer apply on self-hosted Landscape
- The `service.conf` file shipped with Landscape Server now enables computer soft deletion with `computer_soft_deletion = true` under `[features]`. To disable it, set `computer_soft_deletion = false` in the `service.conf` file. When soft deletion is enabled, only the web portal uses the new deletion method
- The Ubuntu installer attach service (`[ubuntu_installer_attach]`) and the WSL hostagent service (`[hostagent_server]`) can now serve TLS when `ssl_server_cert` and `ssl_server_private_key` are set in their section
- Added `PATCH /access-groups/{access_group_name}` to edit an access group
- Added `POST /person:test-email` to send a test email
- Added `POST /users:edit`, which can clear optional fields. `PUT /users` now rejects an empty `location`
- Added `GET /computers/{computer_id}/users/{username}/pending-activities` to list pending activities for a computer user
- `GET /me` now includes the person's global roles
- Activity responses now include the computer title
- Script profiles can now be searched with the REST API
- Upgrade profiles that missed their run window are now skipped
- Improved performance of profile scheduling, alert checks, pending message queries, hardware info message handling, duplicate computer checks, and activity search for soft-deleted computers
- Added an About page to the web portal with information about the web portal and server, and links to useful resources
- Added a Licenses page to the web portal with information on active licenses
- Added web portal side panels to view an access group's details and to edit its title
- The web portal activities table now shows completion time and instance name, and activity details show the creator
- The Users tab and the edit user form in the web portal now show pending user activities
- Added a WSL profile compliance warning to the web portal
- Added administrator limits to the Administrators page in the web portal
- Added an information tip to the Instances page in the web portal with the account name and a link to documentation on registering instances
- The web portal navigation now uses the wording "legacy portal" for the legacy web portal, and the welcome modal presents the web portal as the default
- "Delete script" is renamed "redact script" in the web portal, and the text for scripts and script profiles now says that their titles cannot be reused, even after archiving or redacting
- The primary group is now optional when adding a user in the web portal, and clearing a user's location and phone numbers now works
- Search fields in the web portal now wait for you to stop typing before sending a request

## Upgrade

Database schema changes are required to upgrade to Landscape Server 26.10. You can follow the existing guide to upgrade: {ref}`how-to-upgrade`.

- The OIDC redirect page is now `/portal/handle-auth/oidc` instead of `/new_dashboard/handle-auth/oidc`, and the Ubuntu One redirect page is now `/portal/handle-auth/ubuntu-one/`. See {ref}`how-to-external-auth-oidc`.
- The `landscape_profiles.sh` cron job is replaced by `upgrade_profiles.sh`, `scheduled_profiles.sh`, `script_profiles.sh`, `usg_profiles.sh`, and `cancel_expired_activities.sh`. Each writes to its own log file instead of `landscape-profiles.log`. See {ref}`how-to-manage-maintenance-cron-jobs` and {ref}`reference-logs`.
- The Apache configuration template shipped with Landscape Server now proxies both `/portal` and `/new_dashboard` to the dashboard service.

### Landscape Server charms

The charm revision supporting 26.10 is available in the `26.10/stable` channel.

```{caution}
If you are intending to install Landscape Server version 26.10, we recommend using only the `26.10` charm track.
```

## Bug fixes

- Fixed an HTTP 500 error when a computer has multiple contracts
- Scheduled profiles no longer run on disabled accounts
- Fixed a licensing issue when a client reports Ubuntu Pro information
- The removal profile days limit is now enforced
- Fixed the unapproved activity count when a person has multiple accounts
- The maintenance script now handles each account independently
- The root URL and system email are now read from `service.conf`
- A WSL host's simulated Ubuntu Pro status is now reported as attached
- The `landscape-server` package post-installation script no longer runs a recursive `chown` on `/var/lib/landscape-server` [LP: #1725282](https://bugs.launchpad.net/landscape/+bug/1725282)
- The repository mirror error message now links to the migration guide
- Added validation of LDAP identity values to prevent LDAP injection
- Instance packages in the web portal are no longer shown as security upgrades when they are not installed or when the installed version is newer than the security candidate, and the Security upgrades filter on an instance's Packages tab only lists packages with an available security update
- Fixed snap install, change channel, and hold actions in the web portal not sending the channel, revision, hold time, and classic confinement options, so classic-confined snaps can now be installed
- Fixed USG profile schedule end dates showing as "Invalid date" in the web portal, USG profile run times outside UTC, and the USG audit download form defaulting to a future date
- The web portal now shows an error when creating a role or a USG profile fails
- Fixed invitation links redirecting signed-in users to the home page instead of showing the accept or reject form in the web portal
- Fixed consecutive instance removals not working in the web portal
- Pending instances are hidden in the web portal without an error notification when the person does not have permission to view them
- Fixed the licenses table expiration date in the web portal changing with the time zone
- The web portal now shows a WSL host's Ubuntu Pro subscription instead of an empty state
